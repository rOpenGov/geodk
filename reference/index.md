## Plotting

Convenient functions for plotting one or more dansih geographic parts.
All of these function in the same way and allow you to provide a single
name or a vector of names of the areas you would like to plot as well as
fill and color options.

- [`plot_denmark()`](https://ropengov.github.io/geodk/reference/plot_denmark.md)
  : Plot a map of Denmark with given borders
- [`plot_municipalities()`](https://ropengov.github.io/geodk/reference/plot_municipalities.md)
  : Plot selected (or all) municipalities
- [`plot_regions()`](https://ropengov.github.io/geodk/reference/plot_regions.md)
  : Plot selected (or all) regions
