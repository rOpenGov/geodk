# Get all available levels

Get all available levels

## Usage

``` r
get_levels()
```

## Value

This funciton returns all available levels for the `plot_*` functions.

## Examples

``` r
get_levels()
#>  [1] "regioner"                          "kommuner"                         
#>  [3] "sogne"                             "retskredse"                       
#>  [5] "afstemningsomraader"               "politikredse"                     
#>  [7] "landsdele"                         "storkredse"                       
#>  [9] "postnumre"                         "opstillingskredse"                
#> [11] "menighedsraadsafstemningsomraader"
```
